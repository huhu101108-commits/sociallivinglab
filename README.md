# 칠성동 AI 폭염 안전지킴이 v2

대구 북구 칠성동 대상 **연구용** 폭염 위험 정보 웹앱입니다. 기상청 대구 ASOS(143) 자료는 칠성동 내 개별 위치의 실측값이 아닙니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 자료 연결
1. [기상청 기상자료개방포털](https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36)에서 ASOS **대구 143**, **일자료**, 2006~2015 / 2016~2025 CSV를 받습니다.
2. 앱 사이드바에서 두 CSV를 업로드합니다.
3. 또는 [공공데이터포털 ASOS 일자료 API](https://www.data.go.kr/data/15059093/openapi.do) 서비스키를 발급받아 앱에서 2006~2025년 자동 수집을 시도할 수 있습니다. API 사용 승인 및 호출 제한에 따라 실패할 수 있습니다.
4. 쉼터는 지자체에서 검증한 CSV를 별도로 업로드합니다.

## AI 설계
- 전날까지의 관측 기온과 3/7/14/28일 이동 통계, 계절 주기 등으로 **다음 날 최고기온**을 예측합니다.
- Random Forest와 HistGradientBoosting을 비교하고, 마지막 3년을 각각 과거 연도로만 학습해 순차 검증합니다.
- MAE, RMSE, 33°C 이상 날의 정밀도·재현율, 전날 기온 기준과 비교합니다.
- 습도 데이터가 충분한 경우 과거 습도만 입력합니다. 미래 관측값을 피처에 사용하지 않습니다.
- 평가 결과는 모델 성능이며 **실제 온열질환 위험 확률이 아닙니다**.

## 중요 한계
- 2006~2025년 자료만 있으면 2026년 현재 예보를 제공할 수 없습니다. 최신 관측자료와 공식 예보 연동이 추가로 필요합니다.
- 현재 AI는 칠성동 전체를 대표하는 대구 관측소의 기온을 분석하며, 칠성동 내부 구역별 예측·개인 건강위험·무더위쉼터 최적 배치를 주장하지 않습니다.
- 기상청 공식 예보 및 특보를 우선합니다. 쉼터 위치/운영시간은 공식 기관에서 재확인하세요.
- 실행 환경에 인터넷이 연결되지 않으면 API 자동 다운로드가 실패합니다. CSV 업로드는 오프라인에서도 작동합니다.
