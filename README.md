# 칠성동 AI 폭염 안전지킴이 — 위치 + 일주일 AI 예측

GitHub 저장소 루트의 `app.py`, `model.py`, `forecast.py`, `kma_api.py`, `requirements.txt`를 교체하고, `future7.py`, `shelters.py`를 **추가**하세요.

Streamlit Secrets (이미 등록되어 있으면 그대로 유지):

```toml
KMA_FORECAST_KEY = "기상청 API허브 인증키"
ASOS_SERVICE_KEY = "공공데이터포털 ASOS 인증키"
```

무더위쉼터 지도에 실제 쉼터 점을 표시하려면 공식 무더위쉼터 CSV를 `data/shelters.csv`로 업로드하세요. CSV에는 `쉼터명`, `주소`, `위도`, `경도`, `운영시간` 열이 권장됩니다. 실제 데이터가 없는 상태에서는 쉼터 점을 임의로 만들지 않습니다. 공공데이터포털 전국무더위쉼터표준데이터: https://www.data.go.kr/data/15013199/standard.do

브라우저의 '위치 가져오기' 버튼을 누르고 위치 권한을 허용하면 현재 위치가 지도에 표시됩니다. 위치는 지도/거리 계산에만 사용하며 저장하지 않습니다. 브라우저 권한 거부 시 수동으로 칠성동 중심 지도를 볼 수 있습니다.

AI는 오늘 포함 7일(오늘~6일 뒤)을 추정합니다. 2006~2025년 장기 자료에 2026년 1월 1일~어제까지의 최신 관측자료를 합쳐 학습하고, 예측값 재사용 없이 각 날짜를 직접 예측합니다. 먼 날짜의 예측 불확실성은 남아 있으며, 관측 지연이 4일을 넘으면 예측을 표시하지 않습니다. 기상청 공식 예보가 아닙니다.
