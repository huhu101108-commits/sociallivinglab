# 날짜별 예측 정확도 표시 기능

`app.py`의 날짜별 AI 예측과 실제 기온 비교 섹션이 추가되었습니다.

- 기본값: 하루 전(1일차) 예측을 실제 관측과 비교
- 1~7일차 선택 가능
- 날짜 역순 표: 예측 최고기온, 실제 최고기온, 절대오차, 관측 대기 상태
- 선택한 예측일차의 MAE, 오차 추이, 예측/실제 비교 그래프
- 날짜별 CSV 다운로드

기존 `daily_monitor.py`가 `data/prediction_history.csv`를 매일 생성/갱신해야 합니다. 처음에는 실제 기온이 발표되기 전이라 '관측 대기'가 표시될 수 있습니다. 과거 예측을 임의로 생성하지 않습니다.
