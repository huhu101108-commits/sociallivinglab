# AI 자동 개선 기능 (GitHub Actions)

## 설정
1. 이 ZIP의 파일/폴더를 GitHub 저장소 **최상위**에 올립니다. 숨김 폴더 `.github/workflows/train.yml`도 반드시 포함합니다.
2. GitHub → Settings → Secrets and variables → Actions → New repository secret에서 `ASOS_SERVICE_KEY`를 추가합니다. 기존 Streamlit Secrets의 같은 ASOS 인증키를 사용하되, 공개 코드나 채팅에 키를 적지 않습니다.
3. GitHub → Actions → **AI daily improvement** → **Run workflow**로 최초 학습을 실행합니다. 워크플로가 보이지 않으면 파일 커밋 후 Actions 페이지를 다시 엽니다.
4. 성공하면 `artifacts/direct_model.joblib`, `artifacts/manifest.json`, `data/asos_143.csv`가 자동 커밋되고 Streamlit이 변경을 감지해 다시 배포합니다.
5. 이후 매일 오전 4시 20분(KST) 자동 실행을 시도합니다. GitHub Actions 일정 실행은 지연되거나 비활성화될 수 있습니다.

## 학습 원리
- 대구 ASOS 143 관측자료를 갱신하고 1~11일 앞 직접 예측 모델 후보 3개를 비교합니다.
- 후보는 **2023년까지의 목표 기온**으로 학습하고, **2024~2025년**에 대한 미사용 검증 오차(MAE)를 측정합니다.
- 기존 저장 모델의 동일 검증 MAE보다 0.01°C 이상 개선된 경우에만 새로운 후보 설정으로 전체 관측자료를 재학습해 배포합니다.
- 모델 성능이 개선되지 않으면 기존 모델을 유지합니다. 새 관측자료는 매월 갱신됩니다.
- 웹사이트는 학습된 모델 파일을 불러와 예측합니다. 처음 실행에서 모델 파일이 없을 때만 기존 방식으로 학습합니다.

## 중요한 제한
- 검증기간을 반복해서 활용하면 그 기간에 과적합할 수 있습니다. 실제 운영 예측을 날짜별로 저장하고 사후에 실제 기온과 비교하는 별도 전진 검증이 추가로 필요합니다.
- 새 모델의 MAE가 낮아도 미래 기온 예측이 반드시 좋아지는 것은 아닙니다.
- 학습 모델은 신뢰할 수 있는 본인 GitHub 저장소의 파일만 사용해야 합니다. `joblib` 파일은 불신 파일에 대해 로드하면 안 됩니다.
- Streamlit Cloud와 GitHub Actions의 무료 자원/호출 제한에 따라 작업이 실패할 수 있습니다. Actions 실행 로그를 확인하세요.


주의: 현재 검증기간은 2024~2025년으로 고정되어 있으므로 매일 새 관측자료가 쌓여도 검증 점수가 자동으로 개선되지는 않습니다. 일일 관측자료는 저장되지만 모델 변경은 고정 검증 점수가 개선될 때만 일어납니다. 매일의 실제 예측 정확도를 추적하려면 예측 발행 시점의 결과를 별도 저장하고 추후 관측과 비교하는 추가 기능이 필요합니다.
