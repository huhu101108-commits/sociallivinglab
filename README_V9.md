# v9 전국 지역별 관측소 AI + 지도 시각 구분

- 기존 v8 전체 기능/탭/안전시설 API/대구 장기 기온 AI 및 자동 학습 파일 유지.
- 내 위치: **노란 원 + 검은 테두리**, 한파쉼터: **청록 원**으로 구분.
- 전국 22개 대표 관측소: 공공데이터포털 ASOS 일자료를 최근 약 3년 조회해 지역별 다음날 최고/최저기온 회귀 및 강수 발생 분류 모델 학습.
- 학습/검증은 날짜 순서로 앞 80% 학습, 뒤 20% 평가. MAE 및 Brier 점수와 검증 CSV 공개. 이후 전량 재학습하여 최근 관측 기준 1일 예측.
- Streamlit Secrets에 `KMA_ASOS_KEY = "ASOS 일자료 API 인증키"` 추가. 기존 `ASOS_SERVICE_KEY`가 있다면 재사용 가능. 기존 `KMA_FORECAST_KEY`, 무더위/한파쉼터 키 삭제 금지.
- 지역에 관측소가 없는 경우 공식 격자예보만 표시. 7일 AI 강수 예측, 국지성 시간당 폭우 AI, 전국 20년 강수 추세는 **아직 구현하지 않음**.
- ASOS 일강수량 결측은 기온 최고/최저가 모두 있는 날짜에 한해서 0mm로 처리합니다. 이 가정은 일부 날짜에서 오류를 만들 수 있으므로 기상청 자료 정의와 대조가 필요합니다.
- **한계:** 기상청 예보 대비 우수성을 입증하지 않았으며, 이 모델은 과거 관측에 의존하는 1일 통계 모델입니다. 실시간 특보·재난 판단 대체 불가.
