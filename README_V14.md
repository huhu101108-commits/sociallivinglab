# v14 사용자 선택형 세부 메뉴

기존 v13 파일을 유지하고 사이드바 4개 주 메뉴 안에 선택형 세부 메뉴를 추가했습니다.

- 홈: 기능별 바로가기
- 날씨 예측: 기본 정보 / AI 상세 분석 / 정확도 검증(시간당 강수 AI 및 공식 예보 비교) / 기후 패턴 분석 / 대구 공식 예보·위험 감지
- 기온 예측: 기본 정보 / AI 상세 분석(20년 기후) / 정확도 검증(기록된 최고·최저기온 오차)
- 안전시설: 시설 지도 / 행동요령
- 기존 ASOS, 기상청, 무더위·한파쉼터 API 키 이름 및 GitHub Actions 유지

## 배포
압축을 해제하여 기존 GitHub 저장소 루트에 전체 파일을 업로드하고 커밋하세요. Secrets는 기존 설정을 유지합니다.

## 주의
API 실시간 호출과 Streamlit Cloud 실제 배포는 검증되지 않았습니다.
