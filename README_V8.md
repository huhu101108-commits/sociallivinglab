# v8 전국 날씨 예측 / 기온 예측 탭

기존 v7의 모든 기능과 파일을 유지하며 `app.py`의 UI만 3개 탭으로 분리했습니다.

- 날씨 예측: 전국 30개 대표 지역 선택, 기상청 격자 단기예보 강수확률·시간별 강수량 원문·습도·풍속, 관측 CSV에 강수량 열이 있으면 여름철 강수 패턴 비교
- 기온 예측: 기존 칠성동 최고/최저기온 AI 7일 예측, 과거 비교, 오차 분석, 자동 기록을 모두 유지. 전국 기온 AI가 학습됐다고 표시하지 않습니다.
- 안전시설: 기존 전국 무더위/한파쉼터 API, 위치 표시, 다른 시설 업로드, 계절별 행동요령 유지

필수 Secret: 기존 `KMA_FORECAST_KEY`; 무더위/한파쉼터 키와 ASOS 키는 기존 설정 유지.

**정확성 주의**: 전국 날씨 탭은 실제 기상청 예보를 지역별로 보여주는 기능입니다. 새로운 전국 강수 AI를 학습/검증한 것은 아니므로 AI 예측값으로 속이지 않습니다. 기존 기온 AI는 대구 관측소 기반이며 전국 기온 AI로 확대된 것은 아닙니다. 기상청 단기예보 제공 기간 이후에는 날씨 값을 생성하지 않습니다.
