# v15 사용 설명

기존 v14의 앱 코드, API 연결, AI 모델, 자동학습 및 안전시설 기능을 보존하면서 신규 메뉴를 추가했습니다.

## 신규 메뉴
- 내 지역 대시보드: 위치 권한을 허용하면 30개 대표 지역 중 가장 가까운 곳을 선택합니다. GPS 실패 시 수동 선택 가능. 정확한 주소 기반 예보가 아닌 대표 격자예보입니다.
- 전국 호우 위험 지도: 사용자가 버튼을 눌렀을 때 30개 대표 지역의 기상청 단기예보를 요청하고, 강수확률 및 명시적 강수량으로 자체 주의 지표를 산출합니다. 공식 호우특보나 AI 기반 침수예측이 아닙니다. API 30회 조회가 발생할 수 있습니다.
- 기후 장기 분석: CSV 업로드 또는 대구 ASOS 20년 API 데이터로 연간 강수량, 강한 비 일수, 평균 기온을 비교합니다. 유효 관측일 330일 미만 연도 제외.
- 맞춤 알림: 사용자가 페이지를 열어 버튼을 누르면 관심 지역의 예보를 기준과 비교해 화면에서 안내합니다. 백그라운드 푸시, 문자, 이메일 발송은 지원하지 않습니다.
- AI 변수 영향도: 날씨 예측 > AI 상세 분석 > AI 예측 근거. 학습/검증을 시간순으로 나눈 별도 모델의 순열 중요도. 개별 예측의 원인이나 SHAP 값이 아닙니다.
- 모바일: 반응형 여백, 간결한 홈 바로가기 및 기존 사이드바 유지.

## 기존 Streamlit Secrets
KMA_FORECAST_KEY, KMA_ASOS_KEY (또는 ASOS_SERVICE_KEY), SAFETYDATA_SERVICE_KEY, SAFETYDATA_COLD_SERVICE_KEY를 그대로 사용합니다. 인증키를 GitHub 코드에 올리지 마세요.

## 한계
실제 API 인증 호출, Streamlit Cloud 배포 테스트는 환경의 인증키가 없어 수행하지 않았습니다. API의 접근권한과 호출량에 따라 일부 기능이 제한될 수 있습니다.
