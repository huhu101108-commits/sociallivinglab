# AI 기온 예측 확장

- 최고기온: 기존 모델 유지.
- 최저기온: ASOS tmin 관측자료가 충분하면 별도 직접 1~11일 AI 모델을 학습.
- 2024~2025년 시간순 홀드아웃 검증 후 MAE가 개선된 모델만 채택.
- 현재 예보 기온에 따라 최저기온/최고기온을 자동 우선 표시.
- 기상청 단기예보 및 위험 기상조건 탐지는 기존대로 유지.
- GitHub Actions를 수동 실행하거나 다음 정기 실행을 기다리면 최저기온 모델 파일이 생성됨.
- 최저기온 자료가 없으면 최저기온 AI를 표시하지 않고 기상청 예보를 사용.
- 기상재난 발생 자체를 AI가 예측하는 기능은 아님.
