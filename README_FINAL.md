# 칠성동 AI 기후 안전지킴이 · 최종 안정화 v17

## 유지한 기존 기능
- 홈/내 지역 대시보드/날씨 예측/기온 예측/전국 호우 위험 지도/기후 장기 분석/안전시설 지도/맞춤 알림
- 전국 대표 지역 기상청 공식 예보, 관측소별 AI 예측과 검증, 대구 7일 예측, 기후 장기 분석
- 무더위쉼터·한파쉼터 공식 API, 내 위치 노란색 표시, GitHub Actions 학습

## 최종 안정화 변경
1. 오래된 공식 예보가 호우 위험 지표에 재사용되지 않도록 차단
2. 전국 호우 위험 지도에서 실패 지역 및 오류 유형 표시(인증키는 비노출)
3. 안전시설 지도에서 시설명·주소 검색 지원
4. 홈 화면에서 외부 API 인증 설정 상태와 데이터 출처 확인 가능
5. 오프라인 단위 테스트 및 ZIP 구성 검사 추가

## 배포
GitHub 저장소 루트에 ZIP 내부 파일을 업로드한 뒤 Commit. Streamlit Cloud 메인 파일은 app.py.
기존 Secrets를 유지: KMA_FORECAST_KEY, KMA_ASOS_KEY 또는 ASOS_SERVICE_KEY, SAFETYDATA_SERVICE_KEY, SAFETYDATA_COLD_SERVICE_KEY.
일부 API는 별도 승인 필요. 인증키를 저장소에 커밋하지 마세요.

## 검증 한계
정적 문법 검사 및 오프라인 모의 테스트만 수행. 실제 Streamlit Cloud/기상청/행정안전부 API 호출은 미검증.
관측소 기반 AI는 관측소가 없는 모든 동네의 정밀 예측을 뜻하지 않음. 전국 호우 지도는 기상청 예보 기반 참고 지표로, 실제 침수위험 지도 또는 공식 특보가 아님.
앱 내 맞춤 알림은 접속 시 확인만 지원하며 푸시 알림이 아님.
