# 칠성동 AI 기후 안전지킴이 — 확장 버전

## 새 기능
- 기상청 단기예보: TMP, TMX, TMN, REH, POP, WSD, PCP, SNO(실제로 제공되는 항목만 사용)
- 고온/저온/강풍/저습도/강수 가능성/적설 조건의 참고 위험 안내
- 최근 관측 최고기온과 과거 같은 시기(±7일) 분포 비교
- 7일 AI 최고기온 예측과 과거 같은 시기 분포 비교
- 연도별 고온일수, 최저기온이 존재하면 저온일수 그래프
- 사계절 행동요령

## 기존 기능 유지
- 최고기온 AI 7일 예측, 자동 재학습/검증 워크플로
- 예측 날짜별 오차 기록, 20년 기온 그래프
- 칠성동/북구 무더위쉼터 지도와 위치 표시

## 설치
기존 저장소의 파일을 같은 경로로 업로드합니다. 기존 .github/workflows/train.yml도 유지합니다.
새 파일 climate_risks.py가 반드시 필요합니다.
GitHub Actions에서 다음 실행 시 API에서 수집되는 ASOS 원본에 최저기온(minTa)이 있으면 CSV에도 저장합니다.
이미 저장된 CSV에 최저기온이 없으면 해당 기능은 데이터가 확보될 때까지 표시되지 않습니다.

## 한계
- 최고기온 이외의 AI 직접 예측 모델은 아직 추가하지 않았습니다.
- 한파·호우·건조·강풍의 공식 특보 판정이 아닙니다.
- 미래 예보의 이상기온 비교는 현재 AI 최고기온 모델을 활용한 파생 분석입니다.
- 강수 확률은 집중호우 강도를 의미하지 않습니다.
- 실제 웹 배포/API 호출은 이 환경에서 검증하지 않았습니다.
